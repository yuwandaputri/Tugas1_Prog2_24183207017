Penjelasan singkat tentang Class dan Atribut yang digunakan :
1. Class : Buku
Mendefinisikan struktur umum yang harus dimiliki oleh setiap objek dalam program, agar bisa membuat banyak buku (Contoh : buku1, buku2, dll).
2.	Atribut
Berfungsi untuk menyimpan data atau status yang unik untuk setiap objek buku yang dibuat. Contoh buku1 akan memiliki judul yang berbeda dengan buku2.
3.	Method tampilkanData()
ini bertugas untuk menjalankan objek, yaitu menampilkan isi semua atribut:
•	Judul Buku
•	Penulis
•	Harga 
•	ISBN
•	Penerbit 
•	Tanggal Terbit
•	Halaman
